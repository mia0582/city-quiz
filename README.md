# 一城一面

12 道原创生活偏好题，从 64 座城市中寻找与你同频的生活。免费，无需登录，适合电脑与手机。

测试入口：[https://mia0582.github.io/city-quiz/](https://mia0582.github.io/city-quiz/)

候选范围覆盖所有省会、自治区首府、4 座直辖市、香港与澳门，以及台湾的台北；另补充苏州、大理、厦门、深圳、青岛、珠海、丽江、三亚、桂林、阳朔、张家界、黄山、泉州、宁波、无锡、扬州、洛阳、开封、大同、烟台、威海、日照、北海、景德镇、景洪（西双版纳）、香格里拉、敦煌、延吉、喀什和舟山。首页可查看完整名单。

按生活节奏、自然亲近、文化探索、社交热度、温暖偏好和成本敏感六个维度匹配，给出一座主推荐和两座备选，以及生活尝试和实际居住时的考虑事项。城市画像为主观生活风格设定，测试供趣味探索。

每位参与者在自己的浏览器中保存进度与最近 50 次结果，可保存 PNG 结果图片、导出和导入 JSON 备份。答案与昵称不上传。1.0 版历史结果继续保留原来的 16 城匹配，新测试使用 1.1 版的 64 城范围。

部署来源为 `main` 分支根目录；替换独立的 `index.html` 即可更新 GitHub Pages。
